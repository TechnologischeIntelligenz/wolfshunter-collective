# Retailer product benchmark

This is a product benchmark, not a copy plan. WOLFSHUNTER COLLECTIVE keeps
the useful outcomes and avoids unsupported claims, forced automation, hidden
fees, stale inventory, and opaque supplier quality.

| Capability | Benchmark pattern | Collective decision |
| --- | --- | --- |
| Discovery | Curated catalogs, filters, niches, fast shipping | Evidence-based buckets: market fit, margin, delivery, inventory, data quality |
| Import | Import List and one-click/bulk import | Import List first; explicit Shopify DRAFT; never auto-publish |
| Economics | Markup rules, margin controls, profit calculator | Retailer margin policy, currency, wholesale/retail preview before DRAFT |
| Supplier quality | Vetted suppliers, stock and delivery visibility | Supplier evidence profile, freshness timestamp, quality and fulfillment gates |
| Product content | Images, descriptions, variants, SEO edits | Editable product proposal with original supplier data preserved |
| Inventory | Real-time or scheduled stock updates, restock alerts | Do not sell stale stock; show freshness and block unsafe actions |
| Orders | Centralized order routing, supplier payment, tracking | Implement only after protected-data scope and tenant-safe event model |
| Brand | Samples, private label, branded invoices/packaging | Later supplier capability; never promise until the workflow is real |
| AI | Trend discovery and product recommendations | AI proposes; evidence, retailer approval, and policy controls decide |
| Support | Guided help and operational automation | Four support modes with safe local fallback and no secrets in prompts |

## Product principle

We do not hide negative signals. We make them actionable: stale stock,
uncertain delivery, missing images, weak margin, and incomplete variants are
visible before import. This is the trust advantage over opaque automation.

## Build order

1. Retailer catalog and DRAFT import must stay stable.
2. Supplier catalog onboarding and product-quality evidence.
3. Fresh inventory and price-list synchronization.
4. Retailer order routing, supplier payment, fulfillment, tracking, and returns.
5. Trend signals from verified catalog and order data—not invented popularity.
6. Samples, branding, private label, and multi-store operations.
